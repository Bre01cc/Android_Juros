## Descrição
Aplicação desenvolvida com o objetivo de calcular **juros simples**, permitindo determinar o valor do **montante final** a partir de um capital inicial, considerando uma taxa de juros e um período de tempo.

O cálculo é realizado com base na fórmula de juros simples:

**J = C × i × t**

Onde:  
- **J** = Juros  
- **C** = Capital inicial  
- **i** = Taxa de juros  
- **t** = Tempo  

O montante final é obtido por meio da seguinte fórmula:

**M = C + J**

Com base nos valores informados pelo usuário, a aplicação realiza o cálculo automaticamente e apresenta o resultado de forma clara e objetiva.
